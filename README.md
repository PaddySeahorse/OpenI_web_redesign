# OpenI_web_redesign

## 一、设计定位：Neural Forge（神经熔炉）

这套设计的核心隐喻是——**"算力驾驶舱"**。

OpenI 的使命是让算力像水电一样普惠给每一个开发者。我选择用"算力控制室"作为视觉母题：深黑底色中流动的电光薄荷数据、节点间流淌的粒子、脉冲闪烁的状态点——把抽象的"算力网络"具象化为可感知的视觉语言。

这不是装饰，而是让用户在打开页面的一瞬间，就理解平台的本质：**算力在这里被分配、被调度、被消耗。**

---

## 二、核心理念（Design Principles）

### 1. 语义先于装饰
每个颜色、每个组件都有意义。

| 元素 | 语义 |
|---|---|
| 电光薄荷 `#00E5C7` | 流动的算力能量、主操作、成功 |
| 暖琥珀 `#FFB347` | 动力、警示、积分/配额 |
| 冷蓝 `#6EA8FF` | 数据、推理类任务 |
| 状态色（绿/红/黄/灰） | 任务运行状态，不读字即可判断 |

颜色不是"好看"的选择，而是信息的载体。

### 2. 一套令牌，贯穿全局
三页共用同一个设计令牌系统（CSS Variables）——色彩、字体、间距、圆角、边框、动效缓动函数全部定义为变量。这保证了：
- 首页的 Hero 动效、工作台的环形图、计算任务页的状态徽章，**视觉血缘一致**
- 未来改动只需改一处变量，全站联动

### 3. 动效即反馈，而非炫技
三页严格遵循**"动效强度与交互频率成反比"**原则：

| 页面 | 动效强度 | 设计意图 |
|---|---|---|
| 首页 | 高 | 营销页，需要"哇"的第一印象；算力网络粒子让抽象概念具象化 |
| 工作台 | 中 | 概览页，环形图/进度条的入场动画是数据的"呼吸感" |
| 计算任务 | 极低 | 高频操作页，仅保留 hover、下拉展开、状态点脉冲；**不做背景动画、不做滚动渐显**——让用户专注任务本身 |

### 4. 信息密度与留白的平衡
- **首页**：大留白、大字号，营造品牌势能
- **工作台**：卡片化分区，信息密度适中
- **计算任务**：表格密集展示，行高压缩至 44px，一屏可看 10 条任务

同一个设计系统，通过**间距尺度和组件密度**的调整，适配不同场景。

## 三、设计系统（Design System）

### 色彩系统
```
背景层：#07090C → #0B0E14 → #0F131C → #161C28 → #1E2533
品牌色：#00E5C7（薄荷） / #FFB347（琥珀）
语义色：#4ADE80 成功 / #F87171 失败 / #FBBF24 警告 / #94A3B8 中性
文本层：#EAF0F6 → #8B97A8 → #5C6675
```
采用**多层背景梯度**创造纵深，避免纯黑的扁平感。

### 排版系统
| 角色 | 字体 | 用途 |
|---|---|---|
| Display | `Unbounded` | 大标题、数字指标（几何感，避开常见 Inter/Space Grotesk） |
| Body | `Sora` | 正文 |
| Mono | `JetBrains Mono` | 任务名、算力数据、代码、状态值 |
| Serif | `Instrument Serif` 斜体 | 点缀性的诗意表达（如"注入澎湃动力"） |
| CN | `Noto Sans SC` | 中文 |

**数字一律用等宽字体**（JetBrains Mono），保证算力数据、时间、时长的视觉对齐与可读性。

### 组件规范
- 圆角：卡片 12-16px，按钮 8-9px，徽章 5-7px
- 边框：统一使用 `rgba(255,255,255,.08/.14)` 两档，不用纯白描边
- 阴影：优先用 `rgba` 半透明柔光，不用纯黑阴影
- 状态：hover → 上浮 2-3px + 边框提亮；active → 品牌色填充

## 四、可访问性与工程考虑

1. **语义化 HTML**：`<header>/<nav>/<main>/<aside>/<footer>` 结构清晰，表格使用 `<table>`
2. **焦点可见**：所有交互元素有明确的 focus 状态（品牌色边框）
3. **对比度**：深色背景上的文字对比度符合 WCAG AA 标准
4. **响应式**：三档断点（1180/860/520px），窄屏自动隐藏侧栏
5. **性能**：Canvas 动画使用 `requestAnimationFrame` 并限制 `dpr`，避免高 DPR 下过度渲染

---

## 五、一句话总结

> **以"算力"为魂，以"控制室"为形——用一致的设计令牌串联营销、概览、操作三种场景，在统一中求差异，在差异中守体系。**

这就是 Neural Forge 设计的核心理念：**技术感不冰冷，信息密度不压迫，动效不喧宾夺主。**
